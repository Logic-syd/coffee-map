## 营业时间及应用修复

继续使用现有 `hours_json` JSON 结构，同一天允许多个时段。前端已改为读取真实字段 `hours_json`，营业判断遍历所有时段，并支持跨午夜、上海时区和每分钟刷新。详情页原有逐条显示逻辑可以展示同一天的多个时段。

格式及边界规则见 [营业时间约定](opening-hours.md)。没有补造营业时间，也没有用测试时段更新云端；目前「营业中」筛选不会把没有时段的门店计为营业中，这不代表已核实这些门店关闭。

同时新增 `.env.example`，客户端支持 Supabase Publishable key，并兼容旧版 anon key。本机配置在被 Git 忽略的 `.env.local` 中，文档不包含实际公钥。
